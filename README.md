# Simple Interest Calculator

## Project Overview
The **Simple Interest Calculator** is a Bash shell script that calculates simple interest based on user-provided input. It is a beginner-friendly project designed to demonstrate basic scripting, user input handling, and arithmetic operations in a Linux/Unix shell environment.

## Description
Simple interest is calculated using the formula:

SI = (P x R x T) / 100

Where:
- P = Principal amount
- R = Rate of interest (per annum)
- T = Time period (in years)

This project takes these three values as input from the user and outputs the calculated simple interest.

## Features
- Accepts user input for Principal, Rate of Interest, and Time Period
- Calculates simple interest using the standard formula
- Displays the result in a clear, readable format
- Lightweight, dependency-free Bash script

## Getting Started

### Prerequisites
- A Unix/Linux-based system or terminal with Bash installed (e.g., Git Bash on Windows)

### Installation
Clone this repository to your local machine:

git clone https://github.com/atherullah/mcino-Introduction-to-Git-and-GitHub.git
cd mcino-Introduction-to-Git-and-GitHub

### Usage
Run the script from the terminal:

bash simple-interest.sh

You will be prompted to enter:
1. Principal amount
2. Rate of interest
3. Time period (in years)

The script will then display the calculated simple interest.

## Example
Enter the principal amount: 1000
Enter the rate of interest: 5
Enter the time period (in years): 2
The Simple Interest is: 100
